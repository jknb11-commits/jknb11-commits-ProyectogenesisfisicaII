DOMINA EL
ELECTROMAGNETISMO

Bienvenido a una nueva etapa de entrenamiento físico. Durante esta misión estudiarás electricidad, campos eléctricos, potencial, circuitos, magnetismo, inducción, ondas electromagnéticas, óptica y física cuántica.

Las actividades no están diseñadas para simplemente sustituir datos en ecuaciones. Cada misión exige interpretar una situación, construir un modelo físico, estimar, calcular, representar, argumentar y evaluar si el resultado tiene sentido.

Cada actividad tiene una duración aproximada de 90 minutos.
